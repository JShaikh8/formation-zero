The idea: take NFL All-22 coaches film and have a computer break down every play the way a
coach would, then let you ask it questions. Before any vision work, build the spine the vision
will hang on.

## Session 1 — Scaffold, field, play-by-play

- Set up the Python package (working name: gridiron) with tests from the first hour.
- Wrote the NFL field model in real yards: 120 yards long, 53.3 wide, hash marks 23.58 yards
  in from each sideline, every painted line as a named landmark. This is the target the camera
  image will be pinned to later.
- Built the play-by-play puller on nflverse. Verified on Lions at Chiefs, 2023 week 1: 132
  scrimmage plays, each with a stable id that will join film, positions and labels together.

## Session 2 — Personnel, formations, the store

- Parser for personnel strings ("1 RB, 1 TE, 3 WR" becomes 11 personnel) and a formation
  taxonomy built from slots rather than a 96-way classifier.
- A DuckDB store that loads every game's play-by-play and enriches it with those labels.

## Session 3 — The chat brain

- A chat interface over the store, powered by a hosted Claude model. It has exactly two tools:
  filter plays, and aggregate efficiency (EPA per play, success rate, explosive rate). It never
  writes SQL; the queries are built deterministically from a whitelist.
- Verified on the real game: 21 personnel was the most efficient grouping at +0.65 EPA per
  play; third-down passing was the worst at −0.66.
- Nineteen tests passing, then twenty-six after widening the semantic layer.

**What this bought.** A working demo you can talk to, before a single frame of video was
processed. Everything after this plugs into the same play ids.
