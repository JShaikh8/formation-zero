## Session 1 — Stick or restart

- Picked the project back up after five weeks. The original plan file was gone (not on disk, no
  external drive mounted, no git remote). The repository itself became the source of truth:
  four commits, 158 passing tests, working modules for everything decided in June.
- Decision: stick. Restarting would rebuild the same foundation with the same decisions.

## Session 2 — The architecture document

- Wrote the full system blueprint into the repository so it cannot be lost again: five
  components (ingestion, local inference, reasoning router, intelligence, storage and export),
  the tech stack with licenses, the file tree with every planned module, and an eight-milestone
  build order.
- Two refinements to the June decisions: EasyOCR instead of PaddleOCR (Apple Silicon wheels),
  and Python 3.12 through uv instead of staying on system Python 3.9.
- Framed the "views the camera never gave us": the bird's-eye view is the tracking table drawn,
  and the two angles fuse because they are the same play aligned at the snap. The 3D virtual
  camera is positions plus pose. Photoreal re-rendering is explicitly out of scope.
