## Session 1 — Stats Perform client

- nflverse's formation and personnel labels come from a charting partner and did not cover the
  2025 season, so a second play-by-play source was explored: the Stats Perform API.
- Wrote a stdlib-only client (schedule lookup, event play-by-play, cached raw JSON) and a
  normaliser into the same per-play schema. Its per-play "players involved" list, with jersey
  numbers, was the attraction: supervision for reading jerseys off the film.

**Where it went.** On 2026-09-11 this was parked in favour of the NFL's own API, which carries
the same per-play player records. The code stays in the tree, unused. See decision D-013.
